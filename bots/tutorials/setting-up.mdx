## Requirements

Before getting started, please ensure you have the following:

- A new or existing project, configured with a basic Gradle module and using Gradle <EmbeddedVersion reference="gradle" /> via the Gradle wrapper.
- A Java Development Kit version [compatible with Gradle](https://docs.gradle.org/current/userguide/compatibility.html), and at least version <EmbeddedVersion reference="java" />.

## Build Configuration

:::warning

Kord Extensions includes the API dependencies listed on [the version picker page](/bots/versions).
If you need to use them, remember not to depend on them directly.

:::

<Tabs groupId="build-systems">
  <TabItem value="gradle-kotlin" label="Gradle (Kotlin)" default>

    Add the required plugins to your `settings.gradle.kts` file, creating it if it doesn't exist.

    <Snippets.SettingsKTS />

    Then, add the required Gradle plugins to your `build.gradle.kts` file.

    ```kotlin
    plugins {
      kotlin("jvm")
      kotlin("plugin.serialization")

      id("com.google.devtools.ksp")
      id("dev.kordex.gradle.kordex")
    }
    ```

    Finally, finish configuring your `build.gradle.kts` file.

    <Snippets.BuildKTS />

  </TabItem>

  <TabItem value="gradle-groovy" label="Gradle (Groovy)">

    Add the required plugins to your `settings.gradle` file, creating it if it doesn't exist.

    <Snippets.SettingsGroovy />

    Then, add the required Gradle plugins to your `build.gradle` file.

    ```groovy
    plugins {
      id "org.jetbrains.kotlin.jvm"
      id "org.jetbrains.kotlin.plugin.serialization"

      id "com.google.devtools.ksp"
      id "dev.kordex.gradle.kordex"
    }
    ```

    Finally, finish configuring your `build.gradle` file.

    <Snippets.BuildGroovy />

  </TabItem>
</Tabs>

## Further Configuration

The above guide provides a standard configuration that should get you started.
However, we recommend exploring the following options for more ideas:

- We can't recommend using the Shadow plugin to build a runnable JAR with your bot's dependencies, as a group of
  [vibe coders](https://en.wikipedia.org/wiki/Vibe_coding) has taken over the project.
  Instead, we recommend
  [the Gradle distribution plugin](https://docs.gradle.org/current/userguide/distribution_plugin.html).
