# Home

The Kord Extensions Discord Bot framework is a relatively mature framework for writing Discord bots in Kotlin.
It builds upon [the excellent Kord protocol and caching library](https://kord.dev/), taking a bells-and-whistles
approach to supporting your bots.

This framework is somewhat opinionated, so we recommend taking the time to experiment with it and get to know how it
works.
