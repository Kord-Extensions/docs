# Basic Command APIs

All command types extend the `Command` type, which provides some basic common APIs.
These APIs are available regardless of command type, so you should familiarise yourself with them!

<Doc.Container>
  <Doc.Type name="Command" type="abstract class" extends={["Lockable", "KordExKoinComponent"]}>
    Abstract base type representing everything that all commands have in common.

    <Doc.Arguments type="constructor">
      <Doc.Arg name="extension" type="Extension" propType="val">
        The extension that registered this command.
      </Doc.Arg>
    </Doc.Arguments>
  </Doc.Type>
</Doc.Container>

## Functions

<Doc.Container>
  <Doc.Function name="requireBotPermissions">
    Specify any permissions your bot needs to be able to execute the command.
    Permissions will be checked against the command's execution context - the current guild and channel.

    <Doc.Arguments>
      <Doc.Arg name="perms" type={["Permission", "Permissions"]}>
        The permissions your bot requires.
      </Doc.Arg>
    </Doc.Arguments>
  </Doc.Function>
</Doc.Container>

<Doc.Container internal>
  <Doc.Function name="checkBotPerms" open suspend>
    Check the permissions provided via the `requireBotPermissions` function, throwing a `DiscordRelayedException`
    with a suitable error if your boot doesn't have the required permissions.

    <Doc.Arguments>
      <Doc.Arg name="context" type="CommandContext">
        Command context used to check permissions.
      </Doc.Arg>
    </Doc.Arguments>
  </Doc.Function>

  <Doc.Function name="emitEventAsync" returns="Job" open suspend>
    Quick shortcut to emit a `CommandEvent` without blocking the current coroutine.

    <Doc.Arguments>
      <Doc.Arg name="event" type="CommandEvent">
        Event object to emit.
      </Doc.Arg>
    </Doc.Arguments>
  </Doc.Function>
</Doc.Container>

## Properties

<Doc.Container>
  <Doc.Property name="extension" type="Extension" propType="val">
    The extension that registered this command.
  </Doc.Property>

  <Doc.Property name="name" type="key" propType="var" open>
    Command name, used when invoking the command and shown in help commands.
  </Doc.Property>

  <hr className="clear" />

  <Doc.Property name="kord" type="Kord" propType="val">
    Quick access to your bot's backing `Kord` instance.
  </Doc.Property>

  <Doc.Property name="sentry" type="SentryAdapter" propType="val">
    Quick access to [your bot's Sentry adapter](#).
  </Doc.Property>

  <Doc.Property name="settings" type="ExtensibleBotBuilder" propType="val">
    Quick access to [your bot's settings](#).
  </Doc.Property>

  <Doc.Property name="translationsProvider" type="TranslationsProvider" propType="val">
    Quick access to the [registered translations provider](#).
  </Doc.Property>
</Doc.Container>

<Doc.Container internal>
  <Doc.Property name="nameTranslationCache" type="MutableMap<Locale, String>" propType="val" default="mutableMapOf()" open internal>
    Command name translation cache, used to avoid repeated translation calls.
  </Doc.Property>

  <Doc.Property name="requiredPerms" type="MutableSet<Permission>" propType="val" default="mutableSetOf()" open internal>
    Set of permissions required to execute the command, provided via `requireBotPermissions`.
  </Doc.Property>
</Doc.Container>
