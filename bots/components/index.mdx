# Components

Learn about Discord's [message components](https://discord.com/developers/docs/interactions/message-components) and
how to work with them in your bot.

:::info Components v1

Kord only supports Components v1, so Kord Extensions also only supports Components v1.
If you'd like to use Components v2, please test and review
[this Kord pull request](https://github.com/kordlib/kord/pull/1009).

:::
