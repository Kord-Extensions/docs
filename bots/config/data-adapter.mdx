# Data Adapter

The `dataAdapter { }` builder allows you to register a data adapter, responsible for storing the data handled by
storage units.

```kt
ExtensibleBot(TOKEN) {
    // ...

    dataAdapter(::TomlDataAdapter)
}
```

## Builders

<Doc.Container>
  <Doc.Builder name="dataAdapter" lambdaReturns="DataAdapter">
    Register a callback that constructs and returns an alternative implementation of the `DataAdapter`
    type, if needed.
  </Doc.Builder>
