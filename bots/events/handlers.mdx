# Event Handlers

When something happens on Discord, or in your bot's lifecycle, it will fire an event.
You can define event handlers in your extensions to react to these events.

```kt
event<MessageCreateEvent> {
    action {
        if (event.message.content == "hello") {
            event.message.respond("Hello!")
        }
    }
}
```

## Usage

To create an event handler, use the `event {}` builder detailed above.
All event handlers must define an `action`.

### Builders

<Doc.Container>
  <Doc.Builder name="action" receiver="EventContext<T>">
    Register your event handler's action block, defining what it will do when your bot fires a matching event.
    See [the context API](#context-api) section for more information on what you can do here.
  </Doc.Builder>

  <Doc.Builder name="check" receiver="CheckContext<T>">
    Register a [check](/bots/checks), which must pass for the event handler's action block to execute.
  </Doc.Builder>
</Doc.Container>

## Extra Data

All Kord Extensions events extend [the Kord `Event` type](https://dokka.kord.dev/core/dev.kord.core.event/-event/index.html),
which provides a `customContext` property.
Your bot will store a `MutableMap<String, Any>` here for all events it processes, which allows you to store extra data
on event objects as part of processing.

Kord Extensions provides some extra APIs that make using this more convenient.

### Types

The sections below use the following generic types for brevity.

  <Doc.Function name="getOfOrDefault" receiver="M" returns="T" hasGeneric>
    Attempt to retrieve a value from the map stored with the specified `key`, casting it to the given type `T` and
    returning it.
