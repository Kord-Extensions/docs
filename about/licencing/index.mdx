# Licencing Information

Kord Extensions uses a small, specific set of open/public source licences.
We chose these licences to best match our personal intentions for how you should use each project, weighed against the
potential risks and harms that bad actors could cause to us.

We've put together a set of pages to better explain how we think about each licence:

- <Link to="/about/licencing/cc-zero">Creative Commons Zero Licence</Link>, a public domain dedication we use for this
  documentation.
- <Link to="/about/licencing/eupl">European Public Licence</Link>, an open-source licence applied to our
  <Link to="/bots">Discord bot framework</Link>.
- <Link to="/about/licencing/mpl">Mozilla Public Licence</Link>, a less-restrictive license mainly applied to our
  library projects.
