This framework is a lot more convenient when you use our code generators.
The easiest way to set one up is via [our Gradle plugin](/i18n/plugin), but if you're not using Gradle or
can't use the plugin for some reason, you can integrate [our code generators](/i18n/generators) yourself.

:::

## Project Setup

First, follow these basic setup steps:

1. Ensure you have a JDK installed, version 17 or later.
   If you don't already have one, we recommend [Eclipse Temurin](https://adoptium.net/temurin/releases).
2. Add the i18n framework to your project's
   dependencies:
   <EmbeddedVersion reference="i18n" template="dev.kordex.i18n:i18n:(VERSION)" code />

## Next Steps

Once you've set up the dependency, you'll need to configure the framework and set up your translation bundles:

- Learn how to [configure the framework(/i18n/configuration).
- Learn about [translation bundles](/i18n/bundles), and how to use them.
- Learn about [translation keys](/i18n/keys), and how to use them.
- Learn about [the various registries](/i18n/registries), including the class-loader registry.
- Set up a code generator, either by using [our Gradle plugin](/i18n/plugin), or manually integrating
  [our API or CLI](/i18n/generators).
